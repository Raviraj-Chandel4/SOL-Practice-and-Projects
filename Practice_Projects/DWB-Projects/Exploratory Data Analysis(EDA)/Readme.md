# 🔍 SQL – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** using SQL to understand datasets, explore database structures, identify patterns, and extract meaningful insights.

The project contains a collection of SQL queries designed to explore and analyze relational databases. It demonstrates how SQL can be used to investigate data, understand relationships, identify trends, and generate useful information for data-driven decision-making.

## 🎯 Project Objectives

- Explore database structures and understand available datasets.
- Identify tables, columns, and relationships within the database.
- Analyze key business metrics and dimensions.
- Examine customer and product information.
- Identify patterns and trends within the data.
- Extract meaningful insights using SQL queries.

## 📊 Analysis Covered

- **Database Exploration:** Understanding database structures, tables, and columns.
- **Dimensions Exploration:** Exploring categorical data and unique values.
- **Date Exploration:** Understanding date ranges and time-related information.
- **Measures Exploration:** Analyzing numerical values and key business metrics.
- **Magnitude Analysis:** Comparing and evaluating numerical measures.
- **Ranking Analysis:** Identifying top-performing and lowest-performing categories or entities.
